# Bundled Maia-3 model

`maia3-5m.pt` is the Maia-3 5M checkpoint published by the University of Toronto CSSLab.

- Official model card: https://huggingface.co/UofTCSSLab/Maia3-5M
- Official inference code: https://github.com/CSSLab/maia3
- The model card points to the Maia-3 repository for the code and weights license. The repository's AGPL-3.0 license is included here as `AGPL-3.0.txt`.
- The application loads this checkpoint by local path. It does not download the model at startup or during play.
